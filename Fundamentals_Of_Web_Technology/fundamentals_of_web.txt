Server/Domain: 

A server is a computer or program that stores data and gives services 
to other computers. A domain name is the easy-to-read web address people type to find 
a site, like google.com. A DNS server connects the two by changing that text address 
into a computer-readable numbers system. 

What is a Server?
-A powerful computer or software.
-Holds website files, pictures, or data.
-Listens for requests from other devices and sends back data.

What is a Domain Name?
-The text name of a website.
-Replaces hard-to-remember computer numbers called IP addresses.
-Example: wikipedia.org or example.com.

How They Work Together:
-Computers find servers using numbers (IP addresses like 192.0.2.1).
-People use words (domain names) instead of numbers.
-A Domain Name Server (DNS) acts like a phone book to match the domain name to the 
 correct server.

Sub-Domain Name:

-A subdomain is an extra part added to the front of a main domain name to create a 
 separate section of a website. 
-It helps organize different functions of a business under one main brand.

ex:- gemini.google.com
     aws.amazon.com
      ^
  subdomain

TLD(Top Level Domain):

-A top-level domain (TLD) is the very last section of a website address, 
 located right after the final dot. 
-For example, in google.com, the TLD is .com.
