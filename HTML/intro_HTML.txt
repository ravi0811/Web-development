HTML (Hyper Text Markup Language):

What is HTML?
HTML stands for Hyper Text Markup Language
HTML is the standard markup language for creating Web pages
HTML describes the structure of a Web page
HTML consists of a series of elements
HTML elements tell the browser how to display the content
HTML elements label pieces of content such as "this is a heading", 
     "this is a paragraph", "this is a link", etc.

Tags :- HTML tags are the fundamental building blocks of a webpage, used to structure 
        content and instruct web browsers how to display text, images, and links

     <> : Opening Tag
     </ > : Closing Tag
     < /> : Self closing Tag

     <p></p> : Paragraph tag
     <p>lorem</p> : Gives you random text to test
     <p>lorem6</p> : Gives you random 6 words

     <p>Lorem ipsum dolor sit amet consectetur.</p>
      ^   ---------------^--------------------  ^
  opening tag         content              closing tag

Element :- (opening tag + content + closing tag)

Attribute :- An HTML attribute is a modifier used inside an HTML element's opening tag 
             to provide additional information, configure behavior, or alter the default 
             appearance of that element

     <p id= "demoPara">Lorem ipsum dolor sit amet consectetur.</p>
                ^
            attribute
